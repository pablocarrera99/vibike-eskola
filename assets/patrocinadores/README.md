# Logos de patrocinadores

Sube aquí los logos que vayamos a mostrar en la web.

Recomendaciones:
- Preferiblemente PNG con fondo transparente o SVG.
- Nombres simples, en minúsculas y sin espacios. Ejemplo: `nombre-patrocinador.png`.
- Mantener una versión de buena calidad; la web se encargará de mostrarla al tamaño adecuado.

Ruta web de ejemplo:
`assets/patrocinadores/nombre-patrocinador.png`
