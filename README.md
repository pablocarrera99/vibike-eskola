# VITRI Gasteiz Triatloi Kluba - web

Este repositorio contiene la web del club.

## Ver la web publicada

Web actual:

https://pablocarrera99.github.io/vibike-eskola/

## Ver la propuesta VITRI sin sustituir todavía la web actual

Vista previa:

https://pablocarrera99.github.io/vibike-eskola/preview/

La carpeta `preview/` se utiliza para probar la nueva identidad visual antes de sustituir la web principal.

## Verla en tu ordenador

1. Descarga o clona el repositorio.
2. Abre la carpeta.
3. Haz doble clic en `index.html` para la web actual.
4. Para la propuesta nueva, abre `preview/index.html`.

También puedes abrir los archivos directamente desde GitHub para ver o editar el código, aunque para ver el diseño completo es mejor usar GitHub Pages.

## Estructura actual

- `index.html`: página principal actual.
- `escuela.html`: escuela.
- `actividades.html`: actividades.
- `colabora.html`: colaboración y patrocinio.
- `contacto.html`: contacto.
- `style.css`: estilos de la web actual.
- `script.js`: comportamiento del menú.
- `preview/`: nueva propuesta visual de VITRI.

## Identidad visual propuesta

Colores base:

- Naranja: `#FF6A00`
- Morado principal: `#5B168E`
- Morado oscuro: `#24102F`
- Crema: `#F7F3EE`

La propuesta toma como referencia el nuevo logotipo de VITRI: naranja como color protagonista y morado como color secundario de identidad.
